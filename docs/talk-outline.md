## สคริปต์ Demo (4 นาที)

**ก่อนขึ้นพูด**

1. ใน `web/` รัน `npm run dev` แล้วเปิด <http://localhost:3100>
2. ส่องใจล่วงหน้า 1 รอบด้วยเรื่องเดียวกัน ไว้เป็นสำรองใน "ครั้งก่อน ๆ" ถ้า demo สดติดขัด ให้เปิดอันนั้นแทน
3. ปิดการแจ้งเตือนในเครื่อง และขยายหน้าจอให้ตัวหนังสือใหญ่พอสำหรับโปรเจกเตอร์

**บนเวที**

1. **หน้าแรก** อ่านสามคำ: ไม่ทำนาย ไม่ตัดสิน แค่ถาม ชี้ว่า "ทุกอย่างอยู่ในเครื่องนี้เท่านั้น"
2. **ตั้งเรื่อง** พิมพ์ "จะย้ายคณะดีไหม" ทาง: "ย้ายไปคณะที่ชอบ" และ "อยู่คณะเดิมต่อ" (คำตอบทั้งหมดในการ demo ทีมเขียนเอง ไม่ใช่คำตอบจริงของผู้ให้ข้อมูล)
3. **หายใจ** ชวนทั้งห้องหายใจตาม 1 ครั้ง แล้วกด "ข้าม"
4. **ชั้นที่ 1** เลือกไพ่ ตอบสั้น ๆ ทั้งสองทาง แล้วกด **วางคืน** อย่างน้อยหนึ่งครั้งให้ทุกคนเห็น พูดว่า "วางคืนได้ ไม่ต้องบอกเหตุผล สิทธิ์เดียวกับที่ผู้ให้ข้อมูลของเรามี"
5. **ชั้นที่ 2–3** ชี้ให้เห็นว่าพื้นหลังเข้มขึ้นทีละชั้น และอ่านเสียงสะท้อนหนึ่งบรรทัดออกเสียง
6. **กระจก** ชี้ว่าไม่มีคะแนน ไม่มีทางไหนถูกเน้น แล้วพิมพ์ในช่อง "เห็นอะไรในกระจกบ้าง?" หยุดที่ประโยค "การตัดสินใจเป็นของคุณ" สักสองวินาที

**คำตอบสำเร็จรูปสำหรับ demo** (ไพ่ออกแบบสุ่ม ใช้บรรทัดที่ตรงกับใบที่เปิดได้ ตั้งใจเขียนให้ทั้งสองทางมีทั้งแรงดึงและความกลัว เพื่อให้กระจกไม่ดูเหมือนชี้ไปทางใดทางหนึ่ง)

| ไพ่ | ย้ายไปคณะที่ชอบ | อยู่คณะเดิมต่อ |
